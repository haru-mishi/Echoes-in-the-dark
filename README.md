# Echoes in the Dark

A short horror-themed exploration game, built in GameMaker Studio as an
exercise in object-oriented programming — the player, enemies, and each
interactable (locked doors, readable objects) are modeled as separate
objects with their own behavior and state.

## Running it

Download and run `Echoes in the dark.exe` (Windows only, no installation
needed).

## Notes

This repo contains the compiled build only — no source project.
